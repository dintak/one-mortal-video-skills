# 一個凡人的世界：原創歌曲影片製作

本技能把使用者已完成的歌曲和歌詞轉成可播放、可驗收的動態音樂影片。創作者署名為「一個凡人的世界」。保留使用者對歌曲、歌詞、角色、模型、平台、花費上限及發布方式的選擇；不要把一次任務的確認擴張成日後通用授權。

## 適用情境

- 使用者已有原創歌曲、歌詞，想製作人物演唱、男女對唱或說唱影片。
- 使用者要在 Google Colab 使用 ComfyUI 或其他雲端生成工具製作動態畫面、對嘴、字幕和成片。
- 使用者要從中斷的 Colab 工作階段恢復，或整理影片成品、成本與發布包。

若使用者只有一張靜態圖或尚無歌曲／歌詞，先協助補足這個工作流所需素材；不要自行替換已指定的服務或模型。

## 工作方式

1. 先盤點素材與輸出要求，對齊歌曲時長、歌詞時間軸、演唱者分段、畫面比例、角色參考圖、字幕語言、輸出位置及發布平台。
2. 選用當下可用且符合使用者成本限制的模型和執行環境。安裝前查核官方或專案的最新說明；不要把模型開放權重誤當免費 GPU 算力，也不要假設舊安裝指令仍有效。
3. 先以少量短片段做品質樣片，確認人物穩定、衣袖與身體動作自然、背景動態合理、嘴型和演唱段落匹配，再擴大生成。
4. 長片切成可重跑的小片段；每片成功驗證後保存持久檢查點，維護狀態檔和製作紀錄。工作階段中斷後先盤點已保存檔案，再從第一個缺少或損毀的片段續跑。
5. 用使用者提供的原曲作最終音軌，依時間軸製作或校對字幕，合成全片並檢查音畫同步、長度、編碼、黑畫面、音量和字幕可讀性。
6. 交付前說明完成狀態、輸出位置、可觀看連結、總經過時間及能證實的費用。發布影片前依使用者指定的可見性操作；沒有發布要求時只交付本機成品。

完整流程、可復原檢查點、Colab 免費方案限制、驗收表和發布步驟見 [references/end-to-end-workflow.md](references/end-to-end-workflow.md)。遇到模型變更、需要新套件或切換雲端供應商時，先依該參考文件重新盤點費用、條款和素材傳輸範圍。

## 免費方案與時間預期

如果只付 Codex Plus，其餘使用免費模型和免費額度，仍可能完成影片，但通常會花更久。Plus 提供 Codex 使用額度，不會提供 Colab GPU、延長 Colab 執行階段或提高外部服務額度。免費 GPU 供應、執行階段壽命、模型下載時間及可連線次數會變動，可能造成多次等待、重建和重跑；長片可能跨越數天。開始前說明這個不確定性，不保證完成日期，也不把日曆經過時間冒充 GPU 純運算時間。

若使用者要求只用免費工具，禁止自行切換到付費 API、購買點數、升級雲端方案或開始訂閱。遇到免費 GPU 不可用時，先保存進度並回報等待／手動恢復選項；不使用多帳號規避服務限制、不代替使用者解 CAPTCHA，也不承諾在 Codex 工作階段之外持續監控。

## 權限與發布邊界

- Google Drive 掛載通常會授予筆記本整個帳號雲端硬碟的讀寫能力；只在使用者授權後掛載，並將程式的輸入輸出固定到指定資料夾。完成時依使用者要求卸載。
- 每次對外上傳歌曲、歌詞、角色圖或影片前，確認目的地和內容範圍已有清楚授權。平台出現新的服務條款、素材權利或安全確認時，按當下需要取得確認。
- YouTube 的可見性需明確採用使用者指定的公開／不公開／私人設定。上傳成功不等於影片已完成轉碼；核實狀態再交付連結。
- 對 AI 生成或合成媒體，依當前平台欄位和政策如實揭露；不要在沒有依據時宣稱完全真人拍攝、沒有 AI 或已有營利權。
- 不覆寫唯一原件。生成輸出先寫入暫存檔，驗證成功後再以安全方式改名；錯誤檔保留在隔離資料夾供診斷。
