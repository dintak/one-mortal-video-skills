# 一個凡人・場景預演

## 目標

讓每個鏡頭中的人物、道具、出入口與攝影機方向保持可追蹤。預演只驗證空間和鏡頭安排；人物表演與對嘴要在成片階段另行檢查。

## 工作方式

1. 讀定稿劇本和角色設定，列出場景尺寸、固定物、可移動道具、人物起點與終點。缺少尺寸時用相對位置表示，並標註推估。
2. 畫一張平面布置圖，為入口、主要道具和人物位置編號。依劇情順序記下人物移動與物件交接。
3. 為每鏡記錄：拍攝方向、景別、畫面中的人物、動作開始與結束狀態、目光方向，以及與前後鏡的銜接。
4. 有 Blender 或其他 3D 工具時，用簡單幾何體製作可重跑的預演；沒有時用 2D 圖和鏡頭草圖。先檢查鏡位，再投入昂貴的影像生成。
5. 逐鏡檢查左右位置、視線、物件數量與背景是否一致；把無法確認的部分列在交付說明中。

## 交付

提供布置圖、鏡位表，以及每個連續性疑點的鏡號與修正方式。若使用者要給影像模型的提示詞，只描述該鏡可見的人物、動作、構圖、光線和場景約束，並對應鏡號。
